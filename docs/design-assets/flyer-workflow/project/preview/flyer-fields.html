flyerSubtitle
opt
Event subtitle below title on all templates. Medium weight, centered. Hidden when empty. Distinct from tagline and from Heat's script title split.
"highland basement party"
tagline
opt
Secondary genre line — not the event subtitle. Heat: accent below subtitle. Vintage: uppercase below lineup. Iridescent: not shown (genres line is static v1 chrome).
"house / disco / grooves"
photo
opt
Replaces gradient background; template overlay preserves type legibility.
URI / camera roll
audio
opt
3–30s clip for video export. Trimmed in Audio tab. No effect on image export.
URI · trimStart · trimEnd
aspectRatio
opt
Export only: 9:16 or 4:5. Editor preview is always 4:5.
"4:5" (default post)
Static v1 chrome (not in schema yet): Heat badge HAPPY HOUR · 4-7PM; Iridescent genres + age stamp.
