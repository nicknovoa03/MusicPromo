Description
Example
eventName
YES
The headline. 1–3 words is the sweet spot. Long names auto-scale; truncates past 24 characters.
"DISCO"
"NIGHT FEVER"
date
YES
Always uppercase, weekday + month abbrev. Stored as ISO; rendered abbreviated.
"SAT APR 25"
"THURS MAY 14"
time
YES
Start–end. Em dash between. No leading zeros, no AM/PM after a hyphen.
"4PM – 8PM"
"8PM – LATE"
venue
YES
Free-form. Single line. Auto-uppercases in footer, mixed-case in script slots.
"Neon Grotto Rooftop"
city
opt
City, ST. Appended after venue when present.
"Austin, TX"
lineup
opt
Object. Drops off the layout entirely when items is empty.
itemsLineupItem[] — 0–10 performers in display order showSetTimesboolean — toggle in Text tab; times stored but hidden when false layout"grid2col" | "column" | "festival" | "spotlight" — auto-suggested from count introLabelstring | null — "SOUNDS BY", "MUSIC BY", "DJ SET BY", "FEATURING", "WITH", or custom

eyebrow
opt
Category tag. All caps, letter-spaced. Distinct from tagline — this is the what, not the sound.
"ROOFTOP DAY PARTY"
tagline
opt
Genre line. Lowercase, slashes between, accent color.
"house / disco / grooves"
age
opt
Renders as a stamp/pill, never inline.
"18+", "21+"
photo
opt
User artwork. If present, replaces the textured background; overlay opacity slider (0–60%) keeps type legible.
URI / camera roll asset
audio
opt
10–30s clip for video export. Trimmed in the Audio tab. No effect on image export.
URI · trimStart · trimEnd
Every template renders the same schema — the visual treatment changes, the data doesn't. The lineup block is modular: templates declare a zone; LineupBlock fills it. Layout is auto-suggested from performer count but always overridable. Templates are also data-defaulted: an empty flyer still looks complete, not blank.
