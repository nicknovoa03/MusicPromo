MusicPromo
A
Badge · optional
Stamped corner element. Italic, rotated, accent-on-black. Used for happy-hour callouts, age limits, "presented by". Drops off when empty.
B
Eyebrow · optional
All caps, letter-spaced ~2px, accent color. The category tag — ROOFTOP DAY PARTY, WAREHOUSE.
C
Title · required
The display headline. Anton 96px at full size, single word or two-line wrap. Auto-shrinks past 6 characters.
D
Subtitle · optional
The qualifier. Caveat (script) for Heat; italic Inter for Iridescent; Pinyon Script overline for Vintage. Always lowercase.
E
Tagline · optional
Genre line. Lowercase, slash-separated. Accent color. Distinct from the eyebrow — this is the sound, not the category.
F
Lineup · 0–10 acts
Modular LineupBlock. Layout auto-suggested from count: 2–4 → grid, 5–8 → column, 9–10 → festival. Optional intro label above (SOUNDS BY, MUSIC BY, etc.). Set times toggle-able per flyer. Drops off entirely if empty.
G
Footer · required
Date · Time · Venue, pipe-separated, all caps. Hairline accent rule above. The one piece of info every flyer guarantees.
H
Watermark · always
MusicPromo in the bottom-right, low-contrast. Never removable — it's how the app tracks attribution.
